# Клиент SEDSystem

React 18 и Vite. Интерфейс создан для пяти учебных ролей и работы с заявками, закупками, предложениями, договорами и уведомлениями.

```bash
npm install
npm run dev
npm run build
```

По умолчанию клиент обращается к `/api` на том же адресе. В Docker Compose Nginx перенаправляет запросы к серверу, а в режиме разработки это делает Vite. Для отдельного хостинга клиента адрес сервера можно задать через `VITE_API_URL` во время сборки. Для запуска всего проекта используйте Docker Compose из корня репозитория. Для отдельного запуска настройте на сервере `CORS_ORIGIN` под точный адрес клиента.

При входе учётные данные хранятся только в памяти вкладки и отправляются в заголовке HTTP Basic. После перезагрузки страницы необходимо войти заново. Для публичного доступа обязателен HTTPS; используйте исключительно демонстрационные данные.
